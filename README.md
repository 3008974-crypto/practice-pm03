# Учебная практика ПМ.03

Проекты на Java по модулю «Ревьюирование программных модулей».

## Состав репозитория

- PracticePM03 — консольное приложение в Eclipse.
- PracticeNetBeans — форма приветствия и мини-калькулятор.
- LibraryApp — приложение «Зимняя библиотека».

## Функции библиотеки

Каталог книг, поиск по названию и автору, выдача и возврат.
Интерфейс содержит рисуемый логотип и анимацию снежинок.

Данные хранятся в памяти и сбрасываются после перезапуска.

## Запуск

Проекты NetBeans открываются как существующие проекты.
Главный класс библиотеки: library.ui.LibraryApplication.
Главный класс калькулятора: practice.ui.CalculatorForm.

Проект Eclipse импортируется через Existing Projects into Workspace.
Главный класс: practice.demo.PracticeDemo.
